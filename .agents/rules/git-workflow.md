# Git Commit & Push Workflow

- After making edits/changes requested by the user, verify that the project is in a working state.
- Stage all changes, commit with a clear, descriptive message, and push directly to the remote repository (`origin/main`).
- Always pull/rebase cleanly or ensure the local branch is up to date with the latest remote changes without rewriting published history (no force pushing or amending published commits, as the project is synced with Lovable).
